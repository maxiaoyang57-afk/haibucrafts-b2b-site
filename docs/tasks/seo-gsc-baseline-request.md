# GSC Baseline Needed for Query-Level Optimization

To refine the SEO sprint using real search demand, capture the following from Google Search Console after the current release work is stable:

1. Performance > Search results > Date: Last 28 days > Compare previous 28 days.
2. Export or screenshot the Queries tab: clicks, impressions, CTR, position.
3. Export or screenshot the Pages tab with the same metrics.
4. Countries tab.
5. Devices tab.
6. Indexing > Pages summary.
7. Sitemaps status.

Do not change the SEO plan based only on one-day volatility. Use 28-day comparison and query/page trends.
