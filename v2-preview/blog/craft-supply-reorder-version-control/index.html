Reordering Craft Supplies: Keep Product, Sample and Packaging Versions Aligned

“Same as last time” is a useful starting point. A current product reference and a short change record make it a workable reorder instruction.

By HAIBUCRAFT Buyer Resources Updated October 17, 2026

Sourcing guidance for a project-specific discussion. Confirm the applicable steps and terms in writing with HAIBU. See our editorial policy.

A repeat order can look straightforward while carrying several different references: an old quotation, a retained sample, a newer product link and revised packaging artwork. Before requesting another batch, bring those references into one record. The aim is to identify exactly what you want repeated and to make any permitted change visible before purchasing decisions are made.

01

Start from the current product code

Copy the current SKU and product link into the new inquiry, then add the previous purchase-order number as a separate reference. Do not ask the supplier to identify a component only from its theme or an old screenshot. Several products can share a bear, fruit or Christmas motif while differing in shape or pack format. For a mixed order, keep each selected product on its own line.

The current pig and cabbage listing is RW20809. If an older internal sheet uses a different reference for that design, map it to the current code in your purchasing record rather than adding a second order line. Keep the historical reference in a notes field so previous orders remain traceable. A code correction alone does not establish that the physical product, packing or specification has changed.

02

Choose the reference that defines the repeat

Identify the retained sample, approved photograph or written specification that the supplier should compare against. Include the approval date and revision if you have them. If an original sample is unavailable, explain that limitation and request a new confirmation sample rather than describing an unavailable reference as approved.

Separate appearance, dimensions, back or hole configuration and pack composition. A front photograph can help identify a motif, but it cannot establish every feature. For important color or finish requirements, use agreed viewing conditions and a physical reference where practical. Record acceptable differences only after both sides have discussed them; the website does not create an automatic tolerance for a repeat batch.

03

Keep the product revision separate from the packaging revision

A new barcode, label design or selling-unit quantity can change the packed item even when the decorative component stays the same. Give the product specification and packaging artwork their own revision fields. Name the final files explicitly, remove superseded artwork from the production handoff, and check which version appears on the quotation or approval record.

For a private-label reorder, confirm pouch or box format, label position, variable information and carton identification. Ask whether existing packaging stock is proposed for use and decide how it should be handled if the artwork has changed. Do not assume that a previous printed label is suitable for a new destination, audience or finished-product application.

04

Turn each requested difference into a decision

Write the old requirement, proposed requirement, reason and approval status on one line. A change in shade, motif ratio, back shape or inner-pack count may affect different parts of the order. Ask which items need a revised sample, quotation, artwork proof or packing trial. Freeze the agreed version before the order proceeds to the relevant next step.

Avoid scattered instructions such as “use the new color from yesterday” or “keep the old bags except for the sticker.” Refer to a named file or dated record. Where a detail has not been agreed, mark it pending. Unanswered questions are easier to resolve before confirmation than after components and packaging have been combined.

05

Review the reorder as a new order

Confirm quantity and unit, current availability, packing, price basis, destination, required arrival window and proposed milestones. A previous lead time or price is a historical reference, not the terms for the new order. Ask for confirmation of any substitution before accepting it, including whether a proposed mixed assortment preserves your required designs.

Use the final comparison record during sample or pre-shipment review. Record any issue against the relevant requirement and photograph the affected product or pack. Product review, packaging checks and document scope are separate questions; a visually consistent repeat is not evidence that every old report applies to the new order.

06

Close the record after the order

Retain the final product list, approved sample identity, artwork revision, written changes and packing reference together. Link the delivered batch to that record and note which sample was kept for the next reorder. If a correction was made during the order, carry the accepted final version into the master record instead of allowing the first draft to become the next starting point.

For the next inquiry, a compact handoff is enough: current product code and link, previous order reference, the version you want repeated, the changes you request and the questions that remain open. This gives the supplier a precise basis for review without requiring your purchasing team to reconstruct a long conversation.
